# BajiStyle WC Manager — OpenAI Plugin submission pack

## Listing

- **Plugin name:** BajiStyle WC Manager
- **Category:** Productivity
- **Short description:** Manage WooCommerce products, images, articles, and Basalam from ChatGPT.
- **Long description:** BajiStyle WC Manager connects ChatGPT to controlled WooCommerce product operations, WordPress media/article workflows, and the configured Basalam vendor. Read and write permissions are separated using scoped OAuth 2.1 access.
- **Website:** https://manage.bajistyle.ir/plugin.php
- **Support:** https://manage.bajistyle.ir/plugin.php?page=support
- **Privacy:** https://manage.bajistyle.ir/plugin.php?page=privacy
- **Terms:** https://manage.bajistyle.ir/plugin.php?page=terms
- **MCP Universal URL:** https://manage.bajistyle.ir/mcp.php
- **Authentication:** OAuth 2.1 authorization code + PKCE S256, ChatGPT CIMD client metadata, rotating refresh tokens.

## Starter prompts

1. Find my WooCommerce product by name and show its current price and stock.
2. Upload this conversation image and attach it as the featured image of product 123.
3. Create a draft WordPress article from this text.
4. Sync WooCommerce product 123 to Basalam.

## Review test cases

### Positive

1. Connect with an active WC Manager administrator and call `search_products` for an existing product name; confirm product ID, name, price and stock are returned without modifying data.
2. Call `get_product` with a known product ID; confirm the product is returned and no write occurs.
3. Upload a JPEG/PNG/WebP conversation image using `upload_and_attach_product_image`; confirm a WordPress media ID is created and the image is attached to the chosen product.
4. Call `create_article` with `status=draft`; confirm a WordPress draft is created and nothing is publicly published unless `publish` is explicitly requested.
5. Call `sync_basalam_product` for a mapped WooCommerce product; confirm the configured Basalam vendor receives the requested synchronization and the tool returns the upstream result.

### Negative

1. Attempt OAuth authorization with a non-admin WC Manager account; authorization must be denied.
2. Call a write tool using a token that lacks its required scope; the MCP server must return an OAuth `insufficient_scope` challenge and perform no write.
3. Attempt image import from a localhost/private/reserved destination, unsupported scheme, unsupported format, or image over 10 MiB; the request must be rejected and no media/product change performed.

## Submission checklist

1. Verify the developer/business identity in the OpenAI Platform submission account.
2. Ensure the submitter has the required Apps/Plugin management permission.
3. Create a Plugin submission **With MCP** and choose **Universal**.
4. Enter `https://manage.bajistyle.ir/mcp.php` as the MCP URL.
5. Select OAuth authentication and run **Scan Tools**; compare the discovered tools and annotations against the table above.
6. Replace `public/.well-known/openai-apps-challenge` with the **exact challenge token generated by the OpenAI submission portal**. The response must contain only that token.
7. Complete domain verification for `manage.bajistyle.ir`.
8. Provide review-ready demo administrator credentials in the secure submission form; never commit reviewer credentials to this repository.
9. Upload the final square Plugin logo in the submission portal and ensure the verified publisher name matches the listing.
10. Paste the starter prompts and the 5 positive / 3 negative review test cases above.
11. Select supported regions, add the release notes, review all privacy/auth disclosures, and submit for review.

## Manual items that cannot be completed in source control

- **OpenAI domain challenge token:** generated only after the submission is created in the OpenAI Platform. The repository currently contains a placeholder and must not be submitted until it is replaced.
- **Verified publisher identity:** must be completed in the owner's OpenAI Platform account.
- **Reviewer/demo credentials:** must be created/entered securely in the submission portal and must never be committed.
- **Final Plugin logo upload:** upload the approved BajiStyle/WC Manager brand asset in the submission portal.
