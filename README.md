# سیستم مدیریت محصولات ووکامرس (WooCommerce Manager)

اپلیکیشن وب PHP برای مدیریت کامل محصولات ووکامرس از طریق REST API — شامل محصولات ساده و متغیر (Variable)، ویژگی‌ها (Attributes)، تنوع‌ها (Variations)، دسته‌بندی‌ها، تصاویر و کاربران چندسطحی.

## امکانات

- ورود امن با نام کاربری/رمز عبور و نقش‌های **مدیر** و **ویرایشگر**
- افزودن/ویرایش/حذف محصولات **ساده** و **متغیر**
- مدیریت **ویژگی‌ها** (سراسری یا سفارشی) و تولید خودکار ترکیب‌های **تنوع**
- ویرایش قیمت، موجودی و SKU برای هر تنوع به‌صورت جداگانه
- مدیریت **دسته‌بندی‌ها** (سلسله‌مراتبی، همراه با تصویر)
- **آپلود و مدیریت تصاویر** برای هر محصول (گالری + تصویر شاخص) و برای هر تنوع
- مدیریت کاربران پنل با سطح دسترسی متفاوت
- ثبت لاگ فعالیت‌ها (Activity Log)

## پیش‌نیازها

- هاست/سرور با **PHP 8.0+** (پسوندهای curl، pdo_mysql، fileinfo فعال باشند)
- دیتابیس **MySQL/MariaDB**
- یک سایت وردپرس با ووکامرس نصب‌شده و **Consumer Key/Secret** ساخته‌شده از مسیر:
  `WooCommerce → تنظیمات → پیشرفته → REST API → افزودن کلید` (با دسترسی «خواندن/نوشتن»)

## نصب روی هاست

1. **آپلود فایل‌ها**: کل پوشه پروژه را روی هاست آپلود کنید. **فقط پوشه `public/` باید به‌عنوان ریشه دامنه (Document Root)** تنظیم شود. اگر امکان تغییر Document Root ندارید (هاست اشتراکی معمولی)، کل پروژه را در یک زیرپوشه (مثلاً `wc-manager/`) آپلود کنید و صفحات را از مسیر `wc-manager/public/` باز کنید؛ پوشه‌های `config`، `includes`، `sql` به‌خاطر فایل‌های `.htaccess` امنیتی، از بیرون قابل دسترسی نخواهند بود.

2. **ساخت دیتابیس**: یک دیتابیس MySQL بسازید و فایل `sql/schema.sql` را در آن ایمپورت کنید (از phpMyAdmin یا خط فرمان).
   ```
   mysql -u USERNAME -p DATABASE_NAME < sql/schema.sql
   ```
   این کار یک کاربر ادمین پیش‌فرض می‌سازد:
   - نام کاربری: `admin`
   - رمز عبور: `admin123`
   
   **⚠️ حتماً بلافاصله بعد از اولین ورود، رمز عبور را از بخش «کاربران» تغییر دهید.**

3. **تنظیم اتصال دیتابیس**: فایل `config/config.php` را باز کرده و مقادیر زیر را با اطلاعات هاست خود جایگزین کنید:
   ```php
   define('DB_HOST', 'localhost');
   define('DB_NAME', 'نام دیتابیس شما');
   define('DB_USER', 'یوزر دیتابیس شما');
   define('DB_PASS', 'پسورد دیتابیس شما');
   ```
   همچنین در محیط عملیاتی (Production) بهتر است `APP_DEBUG` را `false` کنید.

4. **مجوز پوشه آپلود**: به پوشه `public/uploads/products` مجوز نوشتن (معمولاً ۷۵۵ یا ۷۷۵) بدهید:
   ```
   chmod -R 755 public/uploads
   ```

5. **ورود به پنل**: به آدرس `https://yourdomain.com/login.php` (یا `.../wc-manager/public/login.php`) بروید و با کاربر ادمین وارد شوید.

6. **اتصال به ووکامرس**: از منوی «تنظیمات اتصال»، آدرس فروشگاه و Consumer Key/Secret را وارد کنید و روی «تست اتصال» بزنید تا از صحت اتصال مطمئن شوید.

## نحوه کار تصاویر

از آن‌جا که WooCommerce REST API امکان آپلود مستقیم فایل را ندارد (فقط آدرس URL می‌پذیرد)، این سیستم عکس‌ها را ابتدا روی سرور خودش (پوشه `public/uploads/products`) ذخیره می‌کند و سپس آدرس عمومی آن را به ووکامرس می‌فرستد. ووکامرس/وردپرس به‌صورت خودکار تصویر را از آن آدرس دریافت کرده و در کتابخانه رسانه سایت شما ذخیره می‌کند. بنابراین دامنه‌ای که این پنل روی آن اجرا می‌شود باید از اینترنت در دسترس (Public) باشد تا سایت وردپرسی بتواند تصاویر را دانلود کند.

## ساختار پروژه

```
wc-manager/
├── config/config.php          تنظیمات دیتابیس و برنامه
├── includes/                  کلاس‌های PHP (Database, Auth, WooCommerceClient, Helpers)
├── sql/schema.sql              اسکریمای دیتابیس
└── public/                     ریشه وب (Document Root)
    ├── login.php / logout.php
    ├── index.php                داشبورد
    ├── products.php              لیست محصولات
    ├── product_edit.php          فرم افزودن/ویرایش محصول (ساده و متغیر)
    ├── categories.php            مدیریت دسته‌بندی‌ها
    ├── users.php                 مدیریت کاربران (فقط ادمین)
    ├── settings.php              تنظیمات اتصال (فقط ادمین)
    ├── ajax/                     اندپوینت‌های AJAX
    ├── assets/                   CSS و JS
    └── uploads/products/         محل ذخیره تصاویر آپلودشده
```

## نقش‌های کاربری

| نقش | دسترسی |
|---|---|
| **مدیر (admin)** | همه‌چیز: محصولات، دسته‌بندی‌ها، کاربران، تنظیمات اتصال |
| **ویرایشگر (editor)** | فقط محصولات و دسته‌بندی‌ها |

## نکات امنیتی

- حتماً رمز عبور پیش‌فرض ادمین را تغییر دهید.
- سایت را روی HTTPS اجرا کنید.
- `APP_DEBUG` را در محیط عملیاتی `false` بگذارید تا خطاهای فنی به کاربر نمایش داده نشود.
- پوشه‌های `config`، `includes` و `sql` با فایل `.htaccess` از دسترسی مستقیم محافظت شده‌اند (در هاست‌های مبتنی بر Apache). اگر از Nginx استفاده می‌کنید، باید قوانین مشابه را در تنظیمات سرور اضافه کنید.

## محدودیت‌های شناخته‌شده

- این نسخه داده محصولات را مستقیماً از API ووکامرس می‌خواند (بدون کش/Sync در دیتابیس محلی)، بنابراین همیشه به‌روز است ولی به سرعت اتصال به سایت ووکامرس شما وابسته است.
- ویژگی‌های سراسری (Global Attributes) باید در ووکامرس با پیشوند `pa_` تعریف شده باشند؛ این سیستم به‌صورت خودکار در صورت نیاز Term جدید برای مقادیر وارد شده می‌سازد.
